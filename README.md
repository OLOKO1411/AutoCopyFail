# AutoCopyFail

first you need to run 
```bash
chmod +x AutoCopyFail.sh
```
Then
```bash
./AutoCopyFail.sh
``
This shell script is designed to run CopyFail automatically.
This script does not work on kernel 6 or higher.

Link to the Copy Fail repository that is being used in this script.
https://github.com/slaptat/copyFail30
